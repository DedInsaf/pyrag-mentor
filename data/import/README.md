# Данные погодного проекта

- Архив [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), данные [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Четыре города, почасовые записи за январь 2024 года. Удержанный набор за февраль–март не импортируется в поисковый индекс.
- Расшифровки кодов из [документации Open-Meteo](https://open-meteo.com/en/docs), рекомендации по визуализации написаны для этого проекта. 560 карточек представляют сочетания кодов погоды, типа сцены и времени суток.
- Фотографии каталога появляются после явной отправки на публикацию и проверки модератором. В Git фотографии пользователей не хранятся.

Из корня проекта выполните `poetry run python -m scripts.weather_data import` дважды. Во второй раз для обеих таблиц ожидается `added=0`. Для подготовки отложенных выборок выполните `poetry run python -m scripts.weather_data eval`.
