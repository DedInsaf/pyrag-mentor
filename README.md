# Погода в кадре

Загрузите фото улицы или выберите снимок из каталога и задайте горизонт от 1 до 48 часов.
Сервис показывает почасовой прогноз и визуализацию того же места. Можно разрешить
геолокацию или ввести координаты съёмки вручную. Авторы одобренных фото получают
10 баллов за снимок. Фотографии из личного прогноза в каталог не попадают.

## Запуск на macOS

Нужны Python 3.12 и Poetry. Из корня репозитория:

```bash
poetry install
poetry run python run.py
```

Откройте [главную страницу](http://127.0.0.1:8000/), зарегистрируйтесь, загрузите
JPEG/PNG/WebP до 8 МБ и получите прогноз. В другом терминале запустите кабинет:

```bash
poetry run streamlit run streamlit_app/app.py --server.port 8501
```

В [кабинете](http://127.0.0.1:8501/) войдите с тем же аккаунтом. Доступны прогноз,
каталог, публикация фото, баллы, пакетный прогноз, режимы оценки, модерация и
состояние системы. Для доступа к модерации назначьте роль заранее
зарегистрированному пользователю:

```bash
poetry run python -m scripts.weather_role editor@example.org editor
```

Для базового сценария достаточно SQLite, сетевого доступа к Open-Meteo и
локального режима обработки фото. Для текстового движка YandexGPT заполните
`YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в локальном `.env`. Для AI-редактирования
изображения заполните `HF_TOKEN` с доступом к Inference Providers. При выборе
этого режима фотография передаётся Hugging Face / fal.ai. Hugging Face для
текстовых задач загружает отдельную модель Transformers локально.

## Docker

```bash
cp -n infrastructure/.env.example infrastructure/.env
docker compose -f infrastructure/docker-compose.yml up --build -d
docker compose -f infrastructure/docker-compose.yml ps
curl -f http://127.0.0.1:8080/health
docker compose -f infrastructure/docker-compose.yml exec app python -m scripts.weather_data import
docker compose -f infrastructure/docker-compose.yml exec worker celery -A backend.worker.celery_app:app call weather.index
```

Nginx слушает порт 8080, FastAPI — 8000, Streamlit — 8501. База PostgreSQL,
Redis и Qdrant хранят данные в отдельных томах. Векторная модель при первой
индексации загружается с Hugging Face. Значения паролей в шаблоне предназначены
для разработки, настоящие ключи хранятся в игнорируемых Git файлах `.env`.

## Архитектура и ограничения

FastAPI получает данные Open-Meteo, обрабатывает фото и запускает текстовый
пайплайн. Восемь режимов комбинируют глоссарий, BM25, Qdrant с RRF и агентов
Validator, Critic, Editor под управлением Supervisor. Модератор может исправить
ответ, после чего он становится доступен поиску. Celery обслуживает индексацию,
очистку кэша, пакетные прогнозы, оценку и статистику.

Локальная визуализация меняет свет, цвет и атмосферные эффекты. AI-режим
просит модель сохранить ракурс, однако детали могут измениться. Обе картинки
показывают возможный вид места. Архивные данные используются в текстовом
контексте. Для метрик изображений понадобится корпус снимков того же ракурса
с подтверждённым временем и погодой.
